# Scenes recorded from the original VB game (tools/oracle.sh) and replayed on the Odin core (odin/tests/screens_test.odin).
# One DSL, two interpreters. Frames land in docs/reference/vb/<shot>.txt (216 lines of 384 hue digits).
#
#   scene NAME            a fresh game at the splash screen (a new controller)
#   keys CMD...           press commands, one after another; CMD is Up Down Left Right A B; the screen is drawn after each
#   embark                keys A A: from the splash through the main menu to a new world (lands on the map)
#   neutral               make the game look at the world again (after staging a fight, a death, a win)
#   wait MS               let that many milliseconds pass (the end screens ignore input for the first second)
#   shot NAME             draw once and record the frame
# Staging (the world is random; these make a scene exact). MAP is one of
#   Town Wilderness Healer HealthTrainer Potter DruidHouse Inn EnergyTrainer Cellar
#   avatar MAP COL ROW        put Loxy there
#   terrain MAP COL ROW T     set one cell's terrain      fill MAP C0 R0 C1 R1 T   set a rectangle
#   give ITEM [N]             N items into Loxy's pack     ground ITEM [N]   N items on the cell Loxy stands on
#   equip SLOT ITEM           Loxy wears/wields it (SLOT is Weapon or Head)
#   stat NAME VALUE           a statistic of Loxy (Health, MaximumHealth, Energy, Jools, AdvancementPoints, ...)
#   flag NAME 0|1             a flag of Loxy (KnowsForaging, RatQuest, ...)
#   enemy TYPE                a creature in the cell Loxy stands on (Rat, OliveGlop, CherryGlop, Scarecrow)
#   forage N                  how many finds are left in the cell Loxy stands on
# Scenes avoid anything random on screen: no wilderness left unstaged, no dice.
